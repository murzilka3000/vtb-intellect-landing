## Правила работы (от владельца)

1. **Никаких комментариев в коде** (TSX, SCSS, конфиги). Уже написанные — удалять. Пояснения писать в чате.
2. **После каждой законченной правки: сборка → линтер → коммит → пуш**, без вопроса «запушить?». Сообщение коммита по-русски, в конце строка атрибуции из системного напоминания.
3. Файл `Опрос ВТБ Интеллект.xlsx` (исходные данные заказчика) лежит в корне основного проекта и **не коммитится**. Таблица уже перенесена в `src/data/quizResults.ts`.
4. Пользователь пишет коротко и разговорно; отвечать по-русски, по делу, перечислять что и где изменено.
5. Если владелец говорит «не проверяй, даю добро» — пропустить браузерные проверки, но сборку и линтер всё равно прогнать.

## Команды

```bash
npm run build          # Next 16 (Turbopack), должен проходить без ошибок

git add -A -- . ':!*.xlsx' && git commit && git push
```

Next.js здесь новая версия с изменениями API; при нестандартных вещах читать `node_modules/next/dist/docs/` (см. AGENTS.md).

## Стили

- Сжатие макета 1440 → экран: `dvw(px)` (не больше px и не больше доли vw), `fluid(min, max)` для шрифтов; миксин `mobile` (до 767px). Брейкпоинт-«планшет» там, где нужно, задаётся `@media` вручную.
- Константы: `$gutter: 56px`, `$container: 1808px`, `$radius-section: 50px`.
- Размеры из Figma переносить числами из API, не «на глаз». Размытие в Figma (blur N) ≈ blur(N/2) в CSS.
- Анимации: парение картинок (`float`), пульсация свечения, плавающие пятна; везде отключаются при `prefers-reduced-motion`.
- Картинки результатов и подвала — обычный `<img>` (не `next/image`), чтобы не было потери качества; правило `no-img-element` выключено в `eslint.config.mjs`.

## Тексты

- Предлоги и короткие слова склеены неразрывным пробелом (`&nbsp;` в JSX, ` ` в строках данных). Новые тексты набирать так же.
- Во всех результатах опроса в конце «Почему мы это рекомендуем» стоит предложение про брокерский счёт в ВТБ.
- В маркировке подвала пока заглушка `erid: ...` (ждём номер от заказчика).

## Hero и кристалл

- `HeroCrystal.tsx` — лёгкая Canvas 2D-версия (WebGL-версию убрали: тяжёлая, подозрение на проблемы шрифтов на Android). В Firefox включена облегчённая отрисовка (30 fps, меньше dpr и сегментов), у видео в Firefox снят blur.
- Раскладка: логотип сверху, кристалл по центру свободного места, текст прижат к низу; кристалл масштабируется на больших экранах, текст — нет. Заголовок на мобильном подстраивается под ширину так, чтобы «стратегия инвестиций,» стояли вместе; подзаголовок на мобильном 22px.
- Под текстом тёмный градиент (чёрный, 0 → 72%).

## Опрос и результаты

- Результат берётся из таблицы `quizResults` по номерам ответов (например `"22120"`). Не придумывать свою логику подсчёта.
- Кнопка «Следующая стратегия» листает результаты по кругу с исчезновением/появлением; на мобильном (и после завершения теста) страница прокручивается к началу блока.
- Блок «Уровень риска / Инвестпрофиль» чёрного цвета, у каждой стратегии свой размер/позиция иллюстрации (`art` в `strategies.ts`).
- Ссылки: результаты → `https://www.vtb.ru/personal/investicii/intellect/#how`, подвал → `https://www.vtb.ru/personal/investicii/intellect/`, статья (v2) → `https://frankmedia.ru/310561`. Все открываются в новой вкладке.

## Figma

- Макет в разных копиях файла; актуальные блоки смотреть по ссылкам, которые присылает владелец. Фрейм `final` — основной лендинг.
- Доступ через REST API с персональным токеном владельца (`X-Figma-Token`); токены живут недолго и не сохраняются в проекте или репозитории — просить новый, когда истёк. Figma MCP на тарифе Starter быстро упирается в лимит.
- `GET /v1/files/:key/nodes?ids=...` — структура и стили; `GET /v1/files/:key/images` — исходные картинки по `imageRef`; `/v1/images/...` (рендер) иногда даёт 429.

## Как проверять визуально

Chrome headless с удалённой отладкой (порт 9333, свежий `--user-data-dir`) и скрипты на Node через CDP (`Page.captureScreenshot`, `Runtime.evaluate`): снимать на 1440, 1920, 1280×650 (низкий десктоп), 1024 (планшет), 430 и 360 (телефоны). Для кристалла с WebGL нужен флаг `--enable-unsafe-swiftshader`; для 2D-версии достаточно `--disable-gpu`. Старый сервер перед повторным запуском убивать (`pkill -f "next start"`).
